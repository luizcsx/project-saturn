## About

Project SĀTURN is a revival of the Brick Hill platform, faithfully recreating the 2022-2023 experience with a fresh identity rooted in a Saturn/space theme. It is built entirely by the community, for the community — offering avatar customization, a virtual item bazaar, crews, and a growing game explorer.

This repository contains the full frontend (HTML, CSS, JS) and the serverless backend API that powers authentication and user management, deployed on Vercel with a Supabase PostgreSQL database.

---

## Features

- 🪐 **Explore** — Browse and play community-created games.
- 🛒 **Bazaar** — Virtual item shop with duts & cores economy.
- 👥 **Crews** — Create and manage groups with ranks and alliances.
- 🔐 **Authentication** — Secure registration and login with hCaptcha and JWT session cookies.
- 🌑 **Dark Theme** — Native dark UI faithful to the original platform aesthetic.
